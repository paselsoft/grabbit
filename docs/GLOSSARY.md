# Glossario di Grabbit

| Termine | Inglese | Significa | Non dire |
| --- | --- | --- | --- |
| Link | Link | Un indirizzo da scaricare (YouTube, YouTube Music, Spotify) | URL, input |
| Brano | Track | Una canzone o un video scaricato come audio | track, job |
| Uscita | Release | Un album, singolo o EP | prodotto, pubblicazione |
| Discografia | Discography | Tutte le uscite di un artista | catalogo, opere |
| Barra dei download | Download bar | La barra fissa in basso nella scheda Scarica | footer |
| Già scaricato | Already downloaded | Brano saltato perché il file c'è già | duplicato, skip |
| Cartelle Artista / Album | Artist / Album folders | Dove finisce la musica: Artista/Album/01 - Titolo | struttura, path |
| Singoli | Singles | Cartella dei brani senza album | varie |
| Registro dettagliato | Detailed log | Le righe di yt-dlp | log, console |
